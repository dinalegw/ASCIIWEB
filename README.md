# ASCIIWEB

A web generator that creates websites rendered entirely in ASCII art.

## Overview

ASCIIWEB transforms HTML/CSS content into ASCII art representations, allowing you to generate and serve websites with text-based visuals that work in any terminal or browser.

## Features

- Convert HTML elements to ASCII art
- Terminal-friendly rendering
- Browser-compatible output
- Customizable character sets and dimensions
- Lightweight, no JavaScript dependencies

## Installation

```bash
npm install
```

## Usage

```bash
npm run generate
```
